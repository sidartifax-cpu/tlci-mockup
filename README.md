## 🖼️ How to Replace Images

Every image lives in the `images/` folder. To swap any image:

1. **Prepare your new image** at the recommended size below
2. **Name it exactly the same** as the file you're replacing
3. **Drop it into the `images/` folder** — overwrite the old file
4. Refresh the browser — done ✅

### Recommended Image Sizes

| File | Recommended Size | Notes |
|------|-----------------|-------|
| `logo-nav.png` | ~500px wide | Keep aspect ratio. Dark background. |
| `logo-footer.jpg` | ~400px wide | Keep aspect ratio. Dark background. |
| `logo-popup.png` | ~480px wide | White background version of logo. |
| `hero-background.jpg` | 1400×820px | Full bleed hero. Landscape orientation. |
| `section-praying.jpg` | 900×500px | Used as faint ghost background. |
| `founder-fiyah.jpg` | 500×600px | Portrait orientation. Face centered. |
| `founder-sharon.jpg` | 500×600px | Portrait orientation. Face centered. |
| `founder-jerome.jpg` | 500×600px | Portrait orientation. Face centered. |

## 🚀 Deploying to GitHub Pages

1. Push this entire folder (all files + `images/` folder) to your GitHub repo
2. Go to **Settings → Pages → Deploy from branch → main / root**
3. Your live URL: `https://YOUR-USERNAME.github.io/REPO-NAME`
